# Deskripsi Proyek
Sistem ini dibuat untuk mengelolabeasiswa secara online. mahasiswa dapat melakukan registrasi dengan
mengisi form, mengunggah berkas persyaratan dan melihat hasil status ajuan.

# Penjelasan File Utama
 - config.php
 berisi tentang konfigurasi database (host, username, password, nama database).
 - index.php
 berisi tentang halaman awal yang menampilkan informasi tentang jenis beasiswa.
 - daftar.php
 menampilkan form pendaftaran yang harus diisi mahasiswa yaitu berupa nama, email, no hp, 
 semester, IPK dan berkas.
 - hasil.php
 menampilkan daftar hasil pendaftaran yang tersimpan di database.
 - assets/style.css
 file ini berisi tentang mengatur tampilan halaman agar rapi.
 - upload/ 
 folder untuk menyimpan file persyaratan beasiswa.
